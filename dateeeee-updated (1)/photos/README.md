# 📸 Фото

Это единственная папка, которую нужно трогать, чтобы менять фотографии и картинку для кнопки «Нет».

## Фотографии мест

Используй эти имена:

- `img1.webp`, `img2.webp`, `img3.webp` — Кино
- `img4.jpg`, `img5.jpg`, `img6.jpg` — Монрепо
- `img7.jpg`, `img8.jpg`, `img9.jpg` — Музей йоги Sanskar
- `img10.jpg`, `img11.jpg`, `img12.jpg` — Флорентийская мозаика
- `img13.jpg`, `img14.jpg`, `img15.jpg` — Комарово и Финский залив
- `img19.jpg`, `img20.jpg`, `img21.jpg` — «История всего»
- `img16.jpg`, `img17.jpg`, `img18.jpg` — Futurione Emotions

### Картинка для «Нет»

`cry.png` — картинка со слезами, которая появляется после нажатия «Нет».

**Её можно просто заменить своей PNG-картинкой с тем же именем `cry.png`.**  
Желательно использовать квадратное изображение с прозрачным фоном.

### Важно

- `index.html` менять не нужно, если ты просто заменяешь фото.
- Можно заменить только одну фотографию или сразу несколько.
- Для первого фото каждого слайда используются именно локальные файлы выше.
- Если локального фото нет, сайт использует запасную картинку.
