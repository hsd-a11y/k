## Очень простая замена фотографий

Все фотографии теперь вынесены в отдельную папку:

`photos/`

**Чтобы заменить фото, просто положи своё изображение в эту папку с нужным именем. `index.html` редактировать не нужно.**

Примеры:
- `photos/01-1.jpg` — первое фото первой идеи
- `photos/01-2.jpg` — второе фото первой идеи
- `photos/08-3.jpg` — третье фото последней идеи

Полная таблица есть в `photos/README.md`.

Если какого-то файла нет, сайт использует исходное фото из интернета — поэтому можно заменять фотографии постепенно.

## Запуск

Просто открой `index.html`.
